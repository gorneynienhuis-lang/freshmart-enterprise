# UI-SCOPE-002 · 课程大作业，聚焦商城核心工程

2026-10-18，转达用户最新明确范围。补充UI-FEEDBACK-001，不能把“成熟商业质感”理解为复刻真实公司的全部网站栏目。当前工作顺序以 [PRIORITIES-003.md](PRIORITIES-003.md) 为准：先完成程序与项目，PPT全部暂停，文档限必要契约、交接和实际证据。

项目本质是希望做得优秀的课程大作业。参考国内外成熟平台的购物布局和质感，但多余的协议中心、Cookie同意弹窗、招商招聘、公司新闻、博客、投资者关系、复杂订阅营销、庞大企业页脚等与买东西/课程工程展示无直接关系的内容不做。不要为了像真实企业而堆砌页面、文字与布局。

前台聚焦：商品分类和搜索筛选、商品详情/规格/价格、购物车、地址与预约配送、报价/优惠/运费、沙箱付款、订单状态与补退款、售后/评价。必要的操作说明如称重差额和退款进度直接放在购物流程相关位置，保持简明。

后台聚焦：商品、批次/库存/临期、拣货称重、配送、售后与财务退款、权限、审计、关键监控/测试展示。让老师能直接看到系统功能和工程质量，避免无关企业官网栏目。

仍需成熟桌面布局与真实购物信息密度，但不是所有页面都塞满内容。界面视觉由Claude设计、用户确认；Claude只写约定的视觉目录，不包办整个frontend。非视觉前端、后端、数据接入、联调、测试与部署由Codex承担，见OWNERSHIP-002。当前文档工作只支持实现与记录真实结果，不以扩写报告代替程序进展。请将此范围直接用于当前界面工作，不必为此另开一轮品牌发散研究。

界面展示重点是让用户能购物、让员工能履约和处理售后；现在不围绕PPT或视频包装额外造页面、动效、数据和演示材料。已做素材保留，PPT暂缓不取消最终交付。用户只负责视觉界面确认，常规业务/技术细节由Codex按统一契约推进。
