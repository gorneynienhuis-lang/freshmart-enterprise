# 第一版决策记录

日期：2026-10-18。决策者：Codex，在用户授权范围内。用户最新明确：**只负责可视化界面的确定；前端界面风格必须经用户确认。** 不将日常工程决策重新交用户逐项审批。

| 项目 | 本版决定 | 决策来源 |
|---|---|---|
| 项目目录 | 沿用 Claude 已建立的 `fresh-mall/` | 避免重复目录和覆盖 |
| 视觉与 PPT | Claude 起草，用户确认品牌、配色、布局、关键页面、PPT 视觉；未经确认仅为候选稿 | 用户明确要求 |
| 前端技术 | React + Vite + TypeScript | 当前 Claude 会话可见用户选择 |
| 后端技术 | Java 21 + Spring Boot 4.1 + MySQL 8.4；模块化单体；具体依赖版本实施时锁定 | Codex；详见 ADR-001 |
| 支付与会员 | 沙箱支付、免费注册基础会员，不开通付费会员或真实扣费 | 可复现且不产生账务成本 |
| 称重 | 估重预付，多退少补；上浮不超过10%，补款另建支付单，未结清不可发货，10分钟或配送开始前截止，未付取消并退回已收款 | 保留课程难点并明确异常边界 |
| 部署 | 首先本地 Docker Compose；dev/test/prod 配置分离；不购买服务器或域名 | 当前无采购授权与部署账户 |
| 库存 | 订单预占、拣货确认出库；已拣取消须实物质检回库 | 保持在库量语义一致 |
| 价格 | 分为单位；每500克单价有分母；优惠顺序与固定分摊；满99元免运费，否则6元（演示默认配置） | 可配置演示业务，不代表真实营业承诺 |
| GitHub | `https://github.com/gorneynienhuis-lang/freshmart-enterprise`，私有 | 用户明确要求创建，Chrome已核实Private |

需要用户操作的仅两类：可视化方案确认；真实费用、账户授权等必须本人处理的操作。当前没有阻塞业务契约的待拍板项。项目截止日期尚未提供，不虚构进度承诺。

## 与旧草案的差异

`/api` → `/api/v1`；HTTP 200 承载所有业务错 → 真实 HTTP 错误；分页 `list` → `items`；订单移除 `REFUNDING/REFUNDED`；支付移除 `REFUNDED`；新增待发货与独立退款/补款。会员不是付费等级；管理员不自动继承所有业务角色；付款不再代表实物已出库。旧接口表仅作输入材料。
