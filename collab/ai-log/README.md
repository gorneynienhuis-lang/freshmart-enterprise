# AI 使用记录

任务书要求：**每次使用 AI 都要记录七要素**，并附对话记录、日志或截图。最终会汇总进 PPT 和文档。

- 文件命名：`YYYY-MM-DD-<工具>-<主题>.md`，例 `2026-10-18-Claude-协作骨架.md`
- 截图放 `collab/ai-log/screenshots/`，在记录里引用

## 模板

```markdown
# <日期> · <主题>

| 要素 | 内容 |
|---|---|
| 工具 / 模型 / 版本 | |
| Prompt（原文或要点） | |
| 生成内容（摘要 + 文件路径） | |
| 是否采纳 | 全部 / 部分 / 否 |
| 拒绝理由（未采纳部分） | |
| 人工修改 | |
| 测试验证结果 | |

附件：<截图或对话链接>
```
