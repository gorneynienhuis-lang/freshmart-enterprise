## 1. 对这份PPT的评价

这份PPT可以作为正式汇报的骨架。红白校园元素统一，东小锦的使用克制，业务、权限、架构、资金恢复、AI使用和部署都能找到对应页。最有价值的是没有只展示商城首页，而是讲了状态、库存和退款这些工程问题。29页内容和备注已全部阅读，并生成预览检查。

### 2.1 这次实际检查到了什么

- 公网首页、会员登录和结算页可用，结算能显示地址、预约时段和服务端报价。本次没有在公网提交新订单，原购物车保留。

这里的业务试走是接口操作加网页结果复核，不是已经替你录好了逐按钮演示视频。正式录像仍按下文操作新订单。

## 4. A—J每段录什么、在哪里点

### A：会员选购、结算和付款（第5页，约45秒）

**录前位置**：本机首页，会员已登录。先打开购物车检查有没有以前留下的商品，按你本次想演示的商品自行整理，不要把旧购物车总金额误当本次演示价格。

1. 首页停2秒，显示东华标志、分类、商品和东小锦。
2. 搜索框输入“番茄”，点“搜索”，点“沙瓤番茄”卡片。
3. 点选500g/份的SKU，再点“加入购物车”。如果本段要体现按实重，可在菠菜详情再选500克；番茄包装规格仍属于按件。
4. 点右上角购物车，展示抽屉里的商品与免运费提示。
5. 点“去结算”，选已准备地址和有名额的时段。录下订单金额框与称重提示。
6. 点“提交订单并支付”。出现课程沙箱支付窗口后，点“模拟支付成功”。等到订单为“已支付，待拣货”。
7. 记下这张新订单的订单号，后续B始终使用它。

**结束画面**：订单号与“已支付，待拣货”同时可见。A结束回PPT第6页，解释服务端报价；第6页不用重复下单。

**建议口述**：“会员提交商品、地址和时段，价格由服务端计算。这里是沙箱支付，接下来同一张订单交给拣货和配送岗位。”

**不要照念PPT旧金额61.30元或旧余量29**。金额、临期优惠、库存与时段余量都以当次页面为准。

### B：同一订单跨岗位完成、售后、退款与评价（第7页，约110秒）

这是全片最重要的素材。可分B1—B5录，剪掉切账号、打密码和等待，**保留每段的角色、同一订单标识及前后状态**。不要只拍六张工作台空列表。

**110秒成片分配**：拣货25秒、交接10秒、签收15秒、会员售后20秒、客服15秒、财务/会员结果25秒。真实操作可以录更长，再剪去空档；保留步骤顺序和结果，不改造页面或数据。

先录网页：会员登录后进“工作台”，可看见“此角色没有本工作台的业务操作权限”。这证明界面限制，**还要录服务端状态**。

用Mac终端运行下面两行，字体调到22—26号，窗口只保留当前输出：

```bash
cd '/Users/djy/Desktop/实验四/fresh-mall'
python3 docs/recording/recording-assistant.py permissions
```

输出依次为游客查订单401、会员查拣货403、拣货查退款403、配送查员工403、管理员查财务退款403。停留最后几行5秒。脚本只读取业务接口、创建并退出自己的登录会话，不会更改员工权限。

**结束画面**：`http: 403`和具体角色、路径。不要打开请求Headers里的Authorization；也不用把任何令牌复制到地址栏。

## 6. 最省心的成片方法

### 6.1 先录无声网页素材，再统一讲解

1. 在桌面建文件夹“生鲜商城答辩录屏”。素材命名 `A-会员下单.mov`、`B1-拣货.mov`……`J-公网.mov`，避免最后找不到哪段接哪页。
2. Mac按 **Shift+Command+5**，选择录制整个屏幕或固定区域。在“选项”里选择保存位置；素材可以先不开麦，避免重复收声。正式连讲时选对麦克风。此操作依据[Apple官方录屏说明](https://support.apple.com/zh-cn/102618)。
3. 网页素材录长一点没关系，剪去打密码、切账号和网络等待，不能剪乱订单状态顺序。需要快进时标“操作等待已加速”。
4. 另存一份PPT为“答辩录制用.pptx”，原修复版保留。你可以把对应素材插在原标注“录屏A/B…”的页，或在全屏录制时切到已打开的视频播放器播放。
5. 最后一次统一录讲解：PPT讲到第5页时播放A，结束回第6页；按时间表继续。无声素材配这一次的麦克风旁白，避免双重声音。
6. 成片看总时长，目标14:20，最多15:00。超过时先删表格逐项解释和登录等待，不删业务结果、权限拒绝或异常证据。

如果不熟悉剪辑，也可以整屏连录，PPT与Chrome用Command+Tab切换。但必须先排练一遍，账号登录、对应页面和订单状态都预先准备。29页不适合第一次边找菜单边一镜到底。

### 6.2 PowerPoint切换要点

- 备注是给你看的提示，不是最终视频要展示的“注释页面”。成片录幻灯片放映画面，不录备注编辑区。
- 用窗口放映或把播放窗口与Chrome放在同一桌面，Command+Tab切换，先试一次再正式录。
- 第5页播完A回第6页；第7页播B后回第8页；第9页C后回第10页，依此类推，不要从头重新放映。
- 如果用播放器，先把要播的文件打开并暂停在开头；播放前后留半秒静止，便于剪接。录素材时不要把评委必须看清的字段挡在播放控件下面。
- 不需要录到所有鼠标操作细节，更不必把每个错误码都解释一次。每次切换只讲一条“我做了什么，所以系统如何处理”。

## 8. 什么时候容易卡住，怎么继续

| 现象 | 先做什么 |
| --- | --- |
| localhost打不开 | 用第2.4节的排练启动与status命令；不要另开第二套3306数据库 |
| 登录报参数不合法 | 清空自动填充，重新输入11位号码和本机私有密码，别把公网密码当本机密码 |
| 无配送时段 | 地址必须在服务范围；选未截止时段，必要时明天；不要照抄旧日期 |
| 拣货任务为空 | A需付款成功；用PICKER刷新、检查状态筛选与订单，不拿已完成排练单重复演 |
| 无法交接配送 | 填账户ID `demo-courier`，不是手机号；先确认实拣已完成、需要的补款已结清 |
| 签收失败 | 读取订单A配送中时的新六位码，不用旧截图中的码或订单号 |
| 品质售后不能提交 | 必须勾选订单行、正数数量、范围内金额，上传本订单绑定图片 |
| 财务没有执行按钮 | 客服先领取并审核；财务账号必须与审核人不同；成功退款本来就不再显示执行/重试 |
| 409版本冲突 | 刷新列表，重新打开对话框，不用旧页面连续重试 |
| 429 | 停止重复登录，不对七个常用账号继续尝试；限流素材用独立合成标识辅助命令 |
| 模型没有真实回答 | 按实际说明FAQ降级；需要真实模型则检查已配置的公网，不在视频中展示Key |
| 监控页面打不开 | 当前并没有9090/9091实例；按I段打开归档结果，不为了录屏随便杀进程 |
| 时间快超15分钟 | 删除逐行读表、版本串和重复镜头。优先保留A/B/C/G/I，主线与老师硬要求不丢 |
