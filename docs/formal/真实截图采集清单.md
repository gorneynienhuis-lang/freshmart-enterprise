# 生鲜商城截图任务分工（给三位队友和项目负责人）

本清单按四个人分工：队友一负责用户端页面，队友二负责角色权限，队友三负责源码、测试、监控和异常，项目负责人负责 GitHub 与 Railway。每个人只需要源码压缩包和公网网址即可开始；需要本地运行时，在压缩包解压后的 `freshmart-enterprise/` 根目录操作。

公网网址：`https://freshmart-enterprise-production.up.railway.app/`

如果公网打不开，进入源码包根目录运行：

```bash
./scripts/demo-start.sh
```

然后打开：`http://localhost:5173`

所有截图都保留地址栏。密码、手机号、Cookie、Token、API Key、数据库连接信息和个人隐私必须打码。没有真实结果时，截“代码/配置/未执行状态”，不要用示例数据冒充实测。
