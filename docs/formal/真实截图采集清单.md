# 生鲜商城截图清单（简明操作版）

先解压源码包，进入解压后的 `freshmart-enterprise/` 根目录。网页截图优先使用：

`https://freshmart-enterprise-production.up.railway.app/`

如果公网暂时打不开，在根目录运行 `./scripts/demo-start.sh`，再打开 `http://localhost:5173`。截图保留地址栏，密码、手机号、Cookie、Token、API Key 和数据库连接信息必须打码。

| 编号 | 在哪里截 | 怎么操作 | 截什么 | 文件名 |
|---|---|---|---|---|

## 二、角色与权限截图

都从首页顶部“你好，请登录”进入；登录后打开 `/#/operations`。使用对应角色账号，不要把密码拍进图里。

| 编号 | 角色/位置 | 怎么操作 | 截什么 |
|---|---|---|---|
| AUTH-01 | 游客首页 | 退出登录后打开首页 | 未登录仍可浏览公开商品 |
| AUTH-02 | 未登录订单 | 未登录打开 `/#/orders` | “需要登录”或 HTTP 401 |
| AUTH-03 | 会员订单 | MEMBER 登录后打开 `/#/orders` | 我的订单、地址、继续选购 |
| AUTH-04 | 运营工作台 | OPERATOR 登录后打开 `/#/operations` | 商品、SKU、经营概览或规则 |
| AUTH-05 | 仓储工作台 | PICKER 登录后滚动到“拣货任务” | 批次、计划数量、领取/实拣按钮 |
| AUTH-06 | 配送工作台 | COURIER 登录后滚动到“配送任务” | 交接、配送中、确认签收入口 |
| AUTH-07 | 客服工作台 | SERVICE 登录后滚动到“售后工单” | 领取、查看证据、审核入口 |
| AUTH-08 | 财务工作台 | FINANCE 登录后滚动到“退款执行” | 退款状态、金额、执行/重试入口 |
| AUTH-09 | 管理员工作台 | ADMIN 登录后查看“员工与权限” | 员工、角色、状态、审计入口 |
| AUTH-10 | 越权拦截 | 用低权限账号访问不属于它的工作台功能 | 页面提示或 HTTP 403 |
| AUTH-11 | 资源隔离 | 会员 A 有订单，退出后换会员 B 查看 `/#/orders` | B 看不到 A 的订单；必要时截 HTTP 404 |

终端截图建议按以下命令进行，命令只在解压包根目录执行：

```bash
# 启动本地演示
./scripts/demo-start.sh

# 后端测试
cd backend && ./mvnw -B -ntp test

# 前端检查和构建
cd ../frontend && npm ci && npm run verify && npm run build

# 接口契约校验（回到项目根目录）
cd .. && node scripts/validate-contract.mjs
```

如果没有生成覆盖率、Redis、Prometheus 或退款恢复的真实结果，不要截图示例数据；可以改拍对应配置、测试代码或“未执行/暂缓”状态。
