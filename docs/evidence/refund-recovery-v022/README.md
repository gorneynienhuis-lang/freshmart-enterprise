## 四笔真实故障

四笔金额均1190分。prepare时任务关闭，四笔均PENDING/attempt0/receipt0/预留1190，避免先成功后伪造失败的竞态。主代理随后只重启隔离实例开启jobs。

- transient：真实注入3次提交前超时，自动退避耗尽形成FAILED/DEAD，预留1190不释放；独立财务用原退款号恢复，最终累计attempt4、单receipt、成功退款1190。
- rejected：真实提交前明确拒绝1次形成FAILED/DEAD；独立财务原号恢复，最终累计attempt2、单receipt、成功退款1190。
- lost-ack：渠道成功凭证提交后真实丢ACK1次，最终attempt1、单receipt，补记一次1190且预留归零。
- ui-retry：另一次真实拒绝形成FAILED/DEAD，HTTP verify故意不恢复，供监控保存真实业务FIRING窗口，然后只由真实UI财务操作恢复。

HTTP verify还实际检查会员403、财务陈旧版本409、原请求幂等重放、原executor审计保留，没有另建退款号或重复增加退款预留。
