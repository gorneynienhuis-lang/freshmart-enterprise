# 商品、仓储、经营规则与后台验收

本目录记录 2026-10-18 在本机实际运行的浏览器验收。数据来自保留原历史的 MySQL 与真实 HTTP 接口；没有 mock、拦截响应、清库或数据库补写业务结果。

运行命令（先启动本机 Demo）：

```sh
node frontend/scripts/e2e-operations.mjs
```

脚本仅接受 localhost/127.0.0.1，从 Git 忽略的 `.runtime/demo-accounts.txt` 读取凭据，凭据和 token 不进入报告。每次运行会创建独立合成商品、规格、采购批次及审计记录，最后下架自己的商品；不会删除库存流水或更改种子账户。运营规则和配送容量测试应独占执行，避免其他验收同时改同一组配置。

`result.json` 的最终状态为 `PASSED`：验证 133 次实际响应，JavaScript 错误、缺失素材、序列化响应契约错误均为 0。
