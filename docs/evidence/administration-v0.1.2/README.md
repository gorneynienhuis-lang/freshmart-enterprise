## 复现

先启动完整本机 Demo，保持前后端分别位于 5173 / 8080，然后执行：

```sh
cd frontend
node scripts/e2e-administration.mjs
```

脚本从 Git 忽略、权限受限的 `.runtime/demo-accounts.txt` 读取本机演示密码，不输出密码。只允许 localhost / 127.0.0.1，使用 Chrome headless 和真实浏览器点击，不拦截或模拟 API。需要允许浏览器进程启动与本机网络连接。每次运行产生独立合成员工，并在收尾时停用，**不修改 7 个原演示账号**。证据中的 `sourceSha256` 固定本轮实际前后端输入；服务器公网验收不包含在本轮范围内。
