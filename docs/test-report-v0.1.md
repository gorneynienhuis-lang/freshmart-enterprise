## 结果记录格式

每次运行保存`docs/evidence/<run-id>/manifest.json`：commit、contractVersion、start/end、environment、command、exitCode、caseTotals、failedCases、artifactPaths、notes。原始JUnit结果、并发请求明细、SQL不变量核对、截图/录屏和压测原始输出都保留；报告只引用真实路径和实际统计。截图必须从真实运行得到，不能用合成UI冒充测试通过。

失败必须计入总数；跳过、未执行、阻塞、通过分开。修复后重跑受影响用例并保留旧失败记录，不能删除失败以美化通过率。99.9%可用率必须有足够观察窗口，课程压测不能据此宣称长期生产可用性。
