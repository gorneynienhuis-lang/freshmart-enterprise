## 已核实的官方信息

- 学校为上海的 Donghua University（DHU），不要混用台湾国立东华大学标志。
- 校徽包含DH变形，日月及经纬织物意象；纺织与设计可作为微弱的视觉联系，不需要加入校史栏目。
- 标准色“锦缎红”：RGB **160,2,31**，对应 **#A0021F**；PANTONE 7627 C。辅色为晨曦红 #B81C22、风帆黄 #F8B74A、基石灰 #3E3A39。这些是校方VI事实，**不代表整站必须换红或用户已批准配色**。
- 手册A1.06：校徽四周留白0.2倍徽标高度；网络最小尺寸37px。保留原版比例，勿变形、重绘、加阴影或把文字替换成商城名。
- 松江校区：上海市松江区人民北路2999号；延安路校区：上海市长宁区延安西路1882号。两校区名称与地址已由官网交叉核对。
